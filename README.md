# 练记 · 微信健身训练记录

按动作、重量、次数和每一组记录训练。原生微信小程序源码位于 `miniprogram/`，附带可在云环境运行的浏览器交互预览。

## 当前功能

- 6 个训练部位、22 个常用动作；开始训练时带入常用动作和上次完成组，支持增加、移除组及调整重量和次数。
- 每组独立标记完成；训练备注、日期调整、60 / 90 / 120 秒休息计时。
- 训练日历、历史详情、记录删除、最近 7 周训练量图、最近 12 周训练热力图及部位分布。
- 本机保存进行中的训练和历史；通过剪贴板导出 JSON、粘贴备份恢复。

首次打开显示明确标识的示例数据。开始第一次真实训练时会确认并清空示例，也可在「我的」中提前清空。示例成绩不是用户的历史数据；原截图中无法辨认的动作缩写及成绩没有被当作真实记录导入。

完成训练前会再次确认：只有已勾选的组进入历史，未勾选的组会丢弃。训练量为完成负重组的 `重量 × 次数` 之和，自重动作不计训练量，但计入完成组数。哑铃重量请自行固定使用「单手重量」或「两手合计」口径，并在训练备注中注明，前后保持一致。

## 在微信开发者工具中运行

1. 安装微信开发者工具，导入本项目根目录。
2. 项目配置已将 `miniprogramRoot` 设为 `miniprogram/`，编译类型为小程序。
3. `project.config.json` 的 AppID 有意留空。填入你自己的小程序 AppID；如当前工具和账号支持，也可使用官方测试账号。
4. 编译后在模拟器检查训练、日历、趋势和备份流程，再使用自己的微信账号进行真机预览。

当前版本使用微信本地存储，无需云开发环境、数据库、服务端或额外 API 密钥。浏览器检查不能代替微信开发者工具及真机验证；项目未宣称已经微信真机测试、审核或发布。正式发布需由 AppID 所属账号在微信平台完成。

## 浏览器交互预览与检查

需要 Node.js 20 或更高版本。在项目根目录执行：

```sh
npm ci
npm run dev
```

预览服务默认使用端口 `4173`，可通过 `PORT` 环境变量调整。浏览器预览共用原生页面的 WXML、WXSS 和页面控制器，由项目内的轻量运行时模拟微信交互；它不是微信工具链编译出的小程序。

```sh
npm test                 # 数据模型与页面控制器测试
npm run check            # JS、JSON、WXML 和原生页面路由检查
npm run test:e2e         # Chromium 浏览器交互测试
npm run build:preview    # 生成 dist/ 静态浏览器预览
```

端到端测试需要可用的 Chromium。默认路径为 `/usr/bin/chromium`，其他位置可执行 `CHROMIUM_PATH=/实际路径/chromium npm run test:e2e`。`build:preview` 的产物仍为浏览器模拟预览；原生小程序继续由微信开发者工具编译。

## 数据与备份

记录只在当前设备保存。浏览器预览使用浏览器本地存储，与微信中的数据相互独立。清理微信数据、移除小程序或更换设备可能造成记录丢失，请定期在「我的 → 导出训练记录」复制 JSON，并粘贴保存到你信任的位置。

恢复备份会校验格式并确认后替换当前记录，导入前请先备份。当前不提供账号登录、自动云备份或跨设备同步；这些可作为后续功能。练记提供记录与统计，不提供医学诊断或个性化训练处方。
