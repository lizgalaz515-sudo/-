# 当前版本验证记录

2026 年 10 月 27 日，在当前云实例验证 v1.1：

- 沿用原锁文件中的依赖，无新增运行时依赖；初版环境已执行 `npm ci`，本次仅更新项目自身的版本号。
- `npm run check`：JS 语法、JSON、WXML 结构、项目配置与原生页面文件检查通过。
- `npm test`：58 项测试通过，其中数据模型 25 项、页面控制器 30 项、预览适配 3 项，无跳过项。
- `npm run test:e2e`：7 项 Chromium 流程测试通过，无跳过项。原有记录、重开恢复、日历、计时、备份等流程继续通过；新增覆盖肩部四个预置动作再加第五个自定义动作，重载、完成和备份恢复保留自定义动作，以及改名保留组数据和旧版历史。
- 布局检查模拟微信原生默认按钮宽度与 `mini` 按钮样式，覆盖 402、375、390、430 像素视口，检查训练表格、部位筛选、关闭按钮、休息控件和自定义动作表单均处于屏幕宽度内。
- 旧版存储键和备份版本保持不变。额外检查读取失败时暂停保存与替换，成功重读后才恢复记录，避免用示例覆盖无法读取的旧数据。
- `npm run build:preview`：静态浏览器预览构建成功，输出为忽略的 `dist/`。
- 本目录中的截图为浏览器交互预览，使用演示记录；v1.1 新截图为 `native-iphone16pro.png` 和 `custom-exercise.png`。

用户已在微信真机运行旧版本并反馈布局问题。本轮云端检查直接加载原生 WXML / WXSS、页面控制器和共享数据模型，微信 API 由浏览器适配器模拟，不能代替 iPhone 16 Pro 微信真机复验。当前云实例没有微信开发者工具；发布、输入键盘、原生日期选择器、剪贴板及切换前后台的计时表现仍应在用户手机上检查。源码 AppID 留空，更新原项目应保留用户自己的 AppID。

云环境的 `install_script` 与 `start_skill` 已保存为配置草稿，包含安装、检查、预览启动和就绪验证说明。保存草稿不等于发布；如需保留为后续任务的云环境快照，请在环境设置中审阅并保存配置，然后发布环境。尚未验证新任务中的快照恢复。

当前业务记录仅保存在本机，浏览器与微信的记录各自独立；没有账号、云同步或自动云备份。原截图的动作编号和模糊简写没有被自动导入。
