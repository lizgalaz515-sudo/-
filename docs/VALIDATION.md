# 当前版本验证记录

2026 年 10 月 27 日，在当前云实例验证 v1.3：

- 沿用原锁文件中的依赖，无新增运行时依赖；初版环境已执行 `npm ci`，本次仅更新项目自身的版本号。
- `npm run check`：JS 语法、JSON、WXML 结构、项目配置与原生页面文件检查通过。
- `npm test`：88 项测试通过，其中数据模型 44 项、页面控制器 41 项、预览适配 3 项，无跳过项。
- Chromium 流程测试共 13 项通过：既有 10 项记录、自定义动作、昵称、日历、计时和备份回归，以及新增 3 项递减组流程，无跳过项。
- 递减组覆盖 `7.5×12 → 5×10 → 2.5×8` 统计为 1 组、30 次、160kg；未完成时全组不计入统计，历史逐段展示，复制、下一次训练与备份恢复保留分段。
- 追加段、复制组及下一次训练均有独立标识；小数输入草稿、删除全部追加段恢复普通组、重命名保留各段、十段上限与非法嵌套/重复标识校验均通过。
- 布局检查模拟微信原生默认按钮宽度与 `mini` 按钮样式，覆盖 402、375、390、430 像素视口，检查训练表格、部位筛选、关闭按钮、休息控件和自定义动作表单均处于屏幕宽度内。
- 存储键保持不变；旧格式 1 可继续读取，含递减组的记录使用格式 2，防止旧版程序忽略分段。检查格式 1 递减组自动升级、格式 2 保持标记、写入时保护且不修改调用对象，以及普通旧组格式和数据不变。额外检查读取失败时暂停保存与替换，成功重读后才恢复记录。
- `npm run build:preview`：静态浏览器预览构建成功，输出为忽略的 `dist/`。
- 昵称限制为 20 个字符，空值恢复默认称呼；保存失败时保留之前的昵称，并允许重试。402 像素下测试长昵称和编辑界面不横向溢出。
- 本目录中的截图为浏览器交互预览，使用演示记录；v1.1 截图为 `native-iphone16pro.png`、`custom-exercise.png`，v1.2 昵称编辑截图为 `nickname.png`，v1.3 递减组截图为 `drop-set.png`。

用户已在微信真机运行旧版本并反馈布局问题。本轮云端检查直接加载原生 WXML / WXSS、页面控制器和共享数据模型，微信 API 由浏览器适配器模拟，不能代替 iPhone 16 Pro 微信真机复验。当前云实例没有微信开发者工具；发布、输入键盘、原生日期选择器、剪贴板及切换前后台的计时表现仍应在用户手机上检查。源码 AppID 留空，更新原项目应保留用户自己的 AppID。
