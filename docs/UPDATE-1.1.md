# 更新到 v1.1：自定义动作和手机布局

本次更新补上「杠铃推肩」，支持添加自定义动作与修改本次动作名称，并修复微信原生按钮默认宽度造成的横向溢出。旧版训练数据可以继续读取。

## 已经在手机上使用时

1. 先在手机小程序「我的 → 导出训练记录」保存一份备份。
2. 从 GitHub 的 `Code → Download ZIP` 下载最新版并解压。
3. 关闭微信开发者工具中的项目，把新源码里的 **`miniprogram` 文件夹**复制到原项目，替换原有的同名文件夹。手机小程序代码所需的本次修改都在这个文件夹中。
4. 保留原项目 `project.config.json`、`project.private.config.json`，继续使用自己已经配置的同一个 AppID。打开原项目，重新编译并生成手机预览二维码。
5. 用手机微信扫码打开。进入「我的」可以看到 `v1.1` 字样；检查原来的历史训练与进行中的组是否仍在，再开始记录。

更新代码会继续读取本机原有的存储，既有记录不需要先清空。备份用于在换设备、变更 AppID 或误清本机存储后恢复。浏览器里的数据与手机微信里的数据相互独立。

若日常使用的是体验版，还需从开发者工具上传新版本，在小程序后台将这次上传的开发版本设为体验版，再打开体验版。

## 添加和修改动作

- 「添加训练动作 → 肩部」现在可以分别选择「哑铃推肩」「杠铃推肩」「哑铃侧平举」「绳索面拉」。
- 需要其他动作时，选择「新建自定义动作」，填写名称、部位和负重/自重类型，点击「保存并添加动作」。第四、第五个动作可以继续添加。
- 训练卡片的动作名旁有「改名」。例如把本次「哑铃推肩」改成「杠铃推肩」，会保留已经填写的组、重量与次数；之前的历史记录仍使用原名。
- 自定义名称会保存在动作库，并随 JSON 备份导出和恢复。改名时保留原训练类型，避免把已经记录的重量误转成自重数据。

## iPhone 16 Pro 检查

已在浏览器中覆盖 402、375、390、430 像素宽度，并模拟微信默认按钮样式，检查训练表格、弹窗关闭按钮、部位筛选、自定义表单和休息控件均处于屏幕宽度内。本环境无法替代你的微信真机；更新后请在 iPhone 16 Pro 检查这些控件，以及弹出输入键盘时表单是否能正常上下滚动。
