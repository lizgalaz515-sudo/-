# 更新到 v1.2：设置自己的昵称

## 更新原项目

1. 在手机小程序「我的 → 导出训练记录」保存一份备份。
2. 下载新版源码并解压，用新的 **`miniprogram` 文件夹**替换原项目的同名文件夹。
3. 保留原项目已经配置好的 AppID 与 `project.config.json`、`project.private.config.json`，继续使用相同小程序账号。
4. 重新编译并生成预览二维码，手机微信扫码打开；「我的」底部显示 `v1.2`。

体验版用户还需上传本次代码并在微信后台更新体验版。新版本继续读取本机原来的记录，不需要清空记录。

## 修改首页的「训练者」

进入「我的 → 我的昵称」，填写喜欢的称呼，点击「保存昵称」。也可以点击右上角头像进入设置。首页问候会立即更新，重开小程序后保留；留空保存可以恢复默认「训练者」。

昵称最多 20 个字符，可以使用中文或表情；昵称与训练数据一起保存在本机，并随备份导出和恢复。旧备份没有昵称时仍可读取，默认显示「训练者」。清除示例记录或第一次开始自己的训练会保留已设置的昵称。

修改昵称保留已有历史、进行中的重量和组数，以及自定义动作库。

## 修改微信入口的名称与图标

这部分在小程序对应账号的微信公众平台后台设置，需要账号管理员或有权限的成员操作。个人昵称、导航栏标题和开发者工具项目名称都不会自动改变微信入口的名称或头像。

具体步骤和 `gh_…` 默认展示排查见[设置个人昵称与微信入口名称、头像](WECHAT-BRANDING.md)。当前没有在用户的微信后台执行改名、换头像或发布操作。
