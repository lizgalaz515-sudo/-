# 设置个人昵称与微信入口名称、头像

小程序内的个人昵称，与微信入口展示的小程序名称、头像分别管理。修改一个不会自动修改另一个。

| 想修改的内容 | 在哪里修改 | 影响范围 |
| --- | --- | --- |
| 自己的训练昵称 | 小程序内「我的」页面的昵称设置 | 当前设备内的个人显示 |
| 微信入口的小程序名称、头像 | 微信公众平台的小程序账号后台 | 由微信平台管理的账号展示信息 |
| 页面顶部导航栏标题 | 项目的 `navigationBarTitleText` | 打开小程序后的页面标题 |
| 开发者工具的项目名称 | `project.config.json` 的 `projectname` | 开发者工具中的项目标识 |

## 修改微信入口名称与头像

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，登录这个小程序对应的账号。
2. 在「设置／基本设置」中找到「基本信息」里的小程序名称、头像。后台导航可能调整，以当前界面为准。
3. 按后台提示填写你选定的名称，并上传准备好的图标；图片格式、尺寸等以后台要求为准。
4. 如平台要求提交审核，按提示完成，并查看修改是否已生效。名称能否使用、修改限制和审核要求，以该账号后台显示的规则为准。

这些操作需要账号管理员或有相应权限的成员完成。代码包不能代替后台设置，也不需要为此提供 AppSecret。

## 开发版仍显示 `gh_…` 或默认头像时

截图中的 `gh_…` 是原始 ID 形式的显示，不能据此直接判断代码里的名称没有修改成功。先核对：

- 登录的后台账号，与微信开发者工具当前项目使用的是同一个 AppID。
- 该账号的名称、头像已经设置，且后台显示已生效。
- 信息生效后，关闭并重新打开小程序，刷新微信最近使用入口，再检查展示结果。

不同入口和开发版本的展示可能存在差异。若仍未更新，结合当前账号状态及微信后台提示排查；不要通过清除小程序数据来刷新头像，以免影响本机训练记录。不能保证单纯重新编译或发布就会解决入口展示问题。

「开发版」是版本标识，修改名称、头像或个人昵称不会改变当前版本类型。

## 项目内的品牌文件

- [app.json](../miniprogram/app.json)：全局导航栏标题。
- [pages/index/index.json](../miniprogram/pages/index/index.json)：页面导航栏标题；可覆盖全局标题。
- [pages/index/index.wxml](../miniprogram/pages/index/index.wxml)：页面内的「练记／LIFTLOG」等品牌文案。
- [assets/icons/](../miniprogram/assets/icons/)：页面使用的本地图标，包括哑铃标志。这些图片不会自动成为微信入口头像。
- [project.config.json](../project.config.json)：开发者工具项目名称与 AppID 配置。

本说明区分了代码设置与平台账号设置；未在你的微信后台执行任何修改。
