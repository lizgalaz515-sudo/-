# 练记设计说明

练记面向在训练中逐组记录、训练后回看变化的个人用户。主要操作是「开始训练 → 调整动作和组 → 记录重量、次数并勾选完成 → 保存 → 回看历史」。不要求账号或联网服务即可使用。

## 信息结构

| 入口 | 内容与主要操作 |
| --- | --- |
| 训练 | 本周概览、训练打卡、最近记录；开始或继续训练，编辑每一组、备注，使用休息计时并完成保存 |
| 日历 | 按月浏览训练日期，查看当天记录与训练详情，确认后删除记录 |
| 趋势 | 最近 7 周训练量、12 周训练热力图、各部位完成组数 |
| 我的 | 本机数据说明、导出 JSON、恢复备份及清除示例 |

动作选择与历史详情使用浮层，训练状态保留在当前页面。手机使用底部四入口导航；宽屏预览使用侧边导航，并将概览组织为主区和辅助卡片。

## 视觉与交互

浅灰紫背景、白色卡片与紫色主按钮组成主要层级，绿色用于本机保存提示，淡紫用于训练状态。数字优先呈现次数、组数和训练量，说明文字补充统计口径。页面用哑铃图形和少量图标建立训练主题，避免让装饰遮挡录入区域。

开始训练是首页主操作；完成组用可切换的勾选状态反馈。重量与次数可直接编辑，并检查有效范围。休息计时支持开始、暂停和重置。完成、放弃、删除、导入和清除示例均通过确认提示说明后果。

## 数据含义

- 动作库包含背部、腿部、胸部、肩部、手臂、核心，共 23 个预置动作，并支持自定义名称、训练部位和负重/自重类型。
- 训练动作旁的「改名」仅变更本次动作的引用，保留每组数据；旧动作定义保留供历史记录使用。新名称在动作库中可再次选择。
- 训练量只汇总已完成负重组的重量乘次数；自重训练参与组数统计。哑铃单手或合计重量由用户保持统一口径，并可写入备注。
- 保存到历史时丢弃未勾选的组；过去记录中的完成组可为下一次同动作提供参考。
- 首次展示的记录有示例标识，首次真实训练前确认清空。没有将无法确认含义的截图缩写或成绩冒充用户历史。
- JSON 恢复是替换操作，先校验数据，再确认。记录留在当前设备，用户通过导出保留独立备份。

## 实现与验证边界

微信端使用原生 WXML / WXSS、页面控制器及 `wx` 本地存储。浏览器预览复用这些页面资源，以轻量运行时模拟页面、弹窗和存储，便于检查布局与核心流程。浏览器测试通过不代表微信真机行为已经验证。

当前不包含登录、云端同步、自动云备份或医疗建议。后续可根据用户需要加入跨设备同步；正式发布由用户自己的微信小程序账号完成。

## 微信原生手机布局

微信 `style:v2` 的默认按钮尺寸与浏览器元素不同。所有原生按钮明确使用 `size="mini"`，通过类选择器覆盖尺寸和边距；关闭、完成勾选、筛选和计时按钮分别设置合适宽度。手机端弹层、训练表格与滚动容器限制在可用宽度内，休息控件允许换行，底部导航预留安全区域。桌面浏览器预览保留侧栏与双栏布局。
